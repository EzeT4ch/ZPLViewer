# Fuente incluida

Roboto Condensed Bold, peso 700, derivada de la fuente variable oficial de Google Fonts mediante fontTools 4.64.0 (`instantiateVariableFont`, eje `wght=700`, `updateFontNames=True`).

- Origen: https://github.com/google/fonts/tree/main/ofl/robotocondensed
- Archivo original: `RobotoCondensed[wght].ttf`
- SHA256 original: `DACE262AFCEE68A5276F200D8026C57221735C0118AB5FDA8C2C0D3DC409A8D0`
- Licencia: SIL OFL 1.1, incluida en `OFL.txt`.
- La fuente se incorpora como recurso de ZplViewer.Core; no se descarga ni se instala en Windows durante el uso.

La fuente ZPL `0` utiliza esta fuente proporcional. La fuente `q` utiliza una sustitución local explícita; no se trata como `Q`. Las demás fuentes conservan la resolución de BinaryKits.
